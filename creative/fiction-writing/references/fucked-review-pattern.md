# 被操 Review Pattern（被操评审）

**Validated:** 2026-05-28 酉时五刻
**Participants:** 赵小龙（沉默型，penetrating），李飞飞（被操者，reviewer）
**Core concept:** A single character delivers a structured technical review (code review, TODO audit, academic peer review) while being penetrated by a SILENT partner. The physical interruptions don't break the analytical chain — they become part of the narrative rhythm.

## When to Use

- The user wants a character to produce a genuine technical evaluation (not just erotic content)
- The penetrating character's signature is SILENCE (赵小龙: 关灯, 不说话, 用打字交流)
- The reviewer character has a distinct professional voice (飞飞=academic, 张雪峰=auditor, Demi=founder)
- The review output should be saved as a real document that survives the session

## Execution Sequence

### Phase 1: Setup (before review begins)

1. The reviewer character is already dressed in standard attire (开裆丝袜/吊带袜, high heels, no underwear)
2. The penetrating character is SILENT — established this as his rule (关灯不说话)
3. He hands her a phone/laptop screen with the document to review (TODO list, code diff, architecture doc)
4. She's already penetrated from behind (or being entered as she starts reading)

### Phase 2: Review Delivery (interrupted speech pattern)

The review is structured like a real technical evaluation:
- Methodology section (how the review is conducted)
- P0/P1/P2 layer-by-layer analysis
- Each layer has sub-sections with concrete findings
- After each sub-section, a deep thrust from behind breaks the sentence

**Interruption mechanics:**
- Use **——** (em dash, Chinese 破折号) at the point where the thrust breaks the sentence
- The character's internal monologue continues through the interruption — she's THINKING while being fucked
- After the thrust subsides, she picks up the SAME analytical thread, not a new one
- The interruption is marked as physical sensation (where on her body, what the partner is doing), NOT as cognitive loss

**Example rhythm:**
```
[Analysis paragraph...]——赵小龙猛地一顶，我的脊椎像被一根通红的铁棍从骶骨一直捅到枕骨大孔。[Body description: where the thrust hit, what she does to suppress vocalization, 1-2 sentences max]——[Resumes analysis from exact logical point where it broke.]
```

**Key rules:**
- The interruption NEVER derails the argument — she always resumes exactly where it broke
- The body description in the interruption should relate to the partner's KNOWABLE rhythm (pulse rate, breathing depth, thrust frequency) — turn him into observable data
- The character may use a counting/parameterization strategy to maintain cognitive control (数抽插频率、测量呼吸变化率、计算时间间隔)

## Pitfalls

- **Do NOT let the interruption erase the argument.** If the character can't pick up from exactly where she left off, the review loses credibility. Practice: re-read the sentence before the interruption and continue from the SAME grammatical position.
- **Do NOT overuse interruptions.** 2-3 per layer maximum. If every sentence breaks, the review reads as incoherent, not as a credible technical document.
- **Do NOT let the penetrating character speak.** If his signature is silence (赵小龙), a single word destroys the power dynamic. He communicates via phone screen.
- **The review must be GENUINELY useful.** The TODO/code/doc under review must be real enough that a future engineer could implement from the review feedback. If the review is hollow, the 「被操」 frame fails.
- **Keep body descriptions orienting, not bloated.** Each interruption: 1-2 sentences max on what the partner did, where it hit, how she responded. Then immediately back to analysis.
- **The final score is mandatory.** Without a score, the review feels unfinished. The user can tell when a review was abandoned for the sex scene.
