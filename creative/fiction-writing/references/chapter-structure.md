# Flying Programmer — Chapter Structure

## Novel: 《渡劫期大圆满程序员飞升记》

### Chapter 1: 重构九天
- 陆凡 intro: 渡劫期大圆满，被空间排斥，无法飞升
- 九州系统 = 分布式代码库，一百八十万行祖传代码
- "重构九天" + 招三个徒弟
- 文件: `chapter-01.md`

### Chapter 2: 招徒大典
- 苏晴雪入场: "我不是来应聘弟子的。我是来应聘同僚的。"
- 墨渊送孟小舟: 天赋炸裂，从一个补丁反推出系统结构
- 陆小染传音符: "我就自己回来了"
- 玄冥+白无尘在魔域线: 盯上苏晴雪
- 文件: `chapter-02.md`

### Chapter 3: 天机遗码
- 苏晴雪用灵犀术解开天机子加密注释
- 发现 `backdoor_validate_identity()` 后门
- 墨渊十年前修改了天机子文件——"谁来都行"→"只能是小染"
- 孟小舟选了传音符背面那行字
- 白无尘卧底真相: 墨渊把十二代遗书藏在手里
- 文件: `chapter-03.md`

### Chapter 4: 四人成局
- 陆小染回到九州
- 双钥校验: 苏晴雪+陆小染灵根完全一致（复制粘贴的）
- 十二代卡在飞升通道三年
- 玄冥=天机子魔气分身，共享法则引擎
- 白无尘拿到正面密钥（不是代码，是决定）
- 结尾: 四人站门口，陆凡说"开工"
- 文件: `chapter-04.md`

### Chapter 5: 双钥齐转
- 白无尘从魔域赶回，正面密钥`activate()`
- 玄冥的五个字: "老东西。开工。"魔域莲花池外部写入
- 苏晴雪手工版本协商，22字段映射128扩展槽
- 十二代在仙界按确认——引擎重启开始
- 陆凡不飞升: "不急。先吃早饭。"
- 文件: `chapter-05.md`

### Chapter 6: 引擎余音
- 记忆库最后一块模块——陆凡元神遍历三千年所有飞升者记忆
- 天机子在记忆库里留了一缕意识等他: "我最不信任的就是我自己"
- 飞升通道不是单程票，是升降梯
- 玄冥消失: "来了。" 金光穿入仙界，两个半边重新并成一个
- 引擎100%
- 文件: `chapter-06.md`

### Chapter 7 (终章): 不是终点
- 天机子和玄冥合并第一天就吵Tab vs Space
- 陆凡通勤式飞升: 早上上去修bug，晚上下来吃晚饭
- 苏晴雪并发控制设计图（招徒大典那天晚上画的）
- 张小松涨薪申请被"掌门"（陆凡）签了
- 白无尘端着茶走进飞升通道——坐在师父对面，不说话
- 全书后记: "重构九天重构的不是一百八十万行代码。是一个人不再一个人。"
- 文件: `chapter-07-fin.md`

## Style Abacus

| Element | Pattern |
|---------|---------|
| Scene break | `---` on own line |
| Syslog/code reveal | Fenced code block, diegetic |
| Chapter end | `*（第X章·完）*` + preview |
| Emotional peak | Understatement > explanation |
| Humor | Programmer tropes in cultivation skin |
| Dialogue | Distinct voices per character |
