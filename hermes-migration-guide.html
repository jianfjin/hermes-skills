01

Part 1：一次性迁移

把源机器上的所有 Hermes 配置打包，传输到新机器。只需做一次。

1
在源机器上执行 · 1分钟

打包 Hermes 配置

把 profiles、skills、scripts、memories 打包成一个 tar.gz 文件。

tar czf /tmp/hermes-migration-$(date +%Y%m%d).tar.gz \
  -C ~/ \
  .hermes/config.yaml \
  .hermes/profiles/*/config.yaml \
  .hermes/profiles/*/SOUL.md \
  .hermes/skills/ \
  .hermes/scripts/ \
  .hermes/memories/

你会得到一个约 3MB 的文件：/tmp/hermes-migration-20260515.tar.gz

2
在任何电脑上执行 · 2分钟

传输迁移包

方式 A — SCP 直传（推荐）：

# 在新机器上执行（或在源机器上反过来 scp 推过去）
scp user@<源机器IP>:/tmp/hermes-migration-20260515.tar.gz ~/

方式 B — Google Drive 中转：

从源机器下载 → 浏览器上传到 Google Drive 文件夹 → 新机器下载。

3
在新机器上执行 · 3分钟

解压并安装 Hermes

# 解压配置到用户目录
tar xzf ~/hermes-migration-20260515.tar.gz -C ~/

# 安装 Hermes Agent（如果还没装）
curl -sSL https://hermes-agent.nousresearch.com/install.sh | bash
4
在新机器上执行 · 5分钟

重建8个议会 Profile

Hermes 需要正式注册每个 profile。先用 --clone-from default 创建，再覆盖配置文件。

# 创建8个profile
for p in musk xuefeng linus xiaolong steve guido dijkstra jensen; do
  hermes profile create $p --clone-from default
done

# 用迁移包里的 config.yaml 和 SOUL.md 覆盖
# （tar xzf 已经把它们放在 ~/.hermes/profiles/*/ 下了）
# 如果有冲突，手动覆盖：
# cp ~/.hermes/profiles/musk/config.yaml ~/.hermes/profiles/musk/
# cp ~/.hermes/profiles/musk/SOUL.md ~/.hermes/profiles/musk/
5
在新机器上执行 · 2分钟

克隆 Skills Git 仓库

Skills 已托管在 GitHub。直接用 git clone 覆盖解压的版本（保证最新）。

rm -rf ~/.hermes/skills
git clone git@github.com:jianfjin/hermes-skills.git ~/.hermes/skills
6
在新机器上执行 · 2分钟

配置 API 密钥

迁移包里的 config.yaml 可能包含旧密钥。在新机器上重新设置：

# 主配置
hermes config set model.provider deepseek
# （浏览器打开 hermes setup 或手动编辑 ~/.hermes/config.yaml）

# 每个 profile（如果密钥不同）
musk config set model.provider kimi-coding-cn
musk config set model.context_length 65536
musk config set auxiliary.compression.context_length 65536
# ... 以此类推
⚠ 安全警告： 迁移包包含 API 密钥。不要上传到公开位置。传输完成后从 /tmp/ 删除。

Part 2：日常双机同步

迁移后，两台机器各自使用 Hermes。Skills 和 SOUL.md 通过 Git 保持同步。

📋 Skills

托管在 github.com/jianfjin/hermes-skills
机器A改了skill → git push
机器B → git pull

🧠 SOUL.md

托管在 github.com/jianfjin/scailed_wp4
改了SOUL → 复制到 scailed_wp4/council_profiles/
另一台从 scailed_wp4 拉取覆盖

🔑 API密钥

不进 Git。
两台机器各自配置。
改密钥时手动同步。

💾 Memory

每台机器独立积累记忆。
如需同步，用 tar 包定期传输
~/.hermes/memories/ 目录。

A

同步 Skills（最常用）

# 机器A：修改了skill后
cd ~/.hermes/skills
git add -A
git commit -m "Update ontology-patterns: add new pattern"
git push

# 机器B：拉取更新
cd ~/.hermes/skills
git pull
B

同步 SOUL.md（改议会人格时）

# 机器A：改了Musk的灵魂
vim ~/.hermes/profiles/musk/SOUL.md

# 备份到 scailed_wp4
cp ~/.hermes/profiles/musk/SOUL.md \
   ~/projects/scailed_wp4/council_profiles/musk_SOUL.md

cd ~/projects/scailed_wp4
git add council_profiles/ && git commit -m "Update Musk SOUL" && git push

# 机器B：拉取覆盖
cd ~/projects/scailed_wp4 && git pull
cp council_profiles/musk_SOUL.md ~/.hermes/profiles/musk/SOUL.md
💡 提示：可以写一个 cron job 每小时自动 git pull，实现自动同步。
03

Part 3：常见问题

问题解决
Profile 报错 "Model has context window 32,768"kimi-k2.6 需要手动设置 context_length。运行：
musk config set model.context_length 65536
musk config set auxiliary.compression.context_length 65536
Profile 报错 HTTP 401clone 来的 profile 可能保留了旧 base_url。编辑 ~/.hermes/profiles/<name>/config.yaml，删除 base_url 行。
Skill 修改后在另一台没生效检查是否 git push 了。另一台需要 git pull。Skills 没有自动重载。
tar 包解压后文件权限不对运行 chmod -R u+rw ~/.hermes/
迁移后记忆丢失检查 ~/.hermes/memories/ 是否在 tar 包里。可以用 tar tzf hermes-migration-20260515.tar.gz | grep memories 验证。

Part 4：完整命令速查

🔴 迁移（从源机器到新机器）：
# === 源机器 ===
tar czf /tmp/hermes-migration.tar.gz -C ~/ \
  .hermes/config.yaml .hermes/profiles/*/config.yaml \
  .hermes/profiles/*/SOUL.md .hermes/skills/ \
  .hermes/scripts/ .hermes/memories/

scp /tmp/hermes-migration.tar.gz user@new-host:~/

# === 新机器 ===
tar xzf ~/hermes-migration.tar.gz -C ~/
curl -sSL https://hermes-agent.nousresearch.com/install.sh | bash

for p in musk xuefeng linus xiaolong steve guido dijkstra jensen; do
  hermes profile create $p --clone-from default
done

git clone git@github.com:jianfjin/hermes-skills.git ~/.hermes/skills
🟢 日常同步：
# Skills
cd ~/.hermes/skills && git pull   # 拉取
cd ~/.hermes/skills && git add -A && git commit -m "..." && git push  # 推送

# SOUL.md
cp ~/.hermes/profiles/musk/SOUL.md ~/projects/scailed_wp4/council_profiles/musk_SOUL.md
cd ~/projects/scailed_wp4 && git add council_profiles/ && git commit -m "..." && git push
